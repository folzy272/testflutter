# Лабораторна робота

**Тема:** Тестування інтерфейсу онлайн-магазину у Flutter (варіант 4).

## Мета роботи

Навчитися створювати Widget-тести та Integration-тести у Flutter, перевіряти
правильність роботи окремих компонентів і проходження повного сценарію
користувача. Для тестування використати `flutter_test`, `WidgetTester`,
`testWidgets` та `integration_test`.

## Хід роботи

Спочатку створено Flutter-проєкт онлайн-магазину. У ньому зроблено каталог із
товарами, для яких вказано назву, ціну, наявність, рейтинг і знижку. Для
відображення товарів використано компонент `ProductCard`. Якщо для товару є
знижка, стара ціна закреслюється, а нова показується поряд. Коли товару немає
в наявності, кнопка додавання до кошика недоступна.

Далі реалізовано кошик. Він показує додані товари, їхню ціну та кількість.
Кількість можна збільшувати й зменшувати, але не менше одиниці. Загальна
сума оновлюється після кожної зміни. Якщо всі товари видалити, відображається
повідомлення про порожній кошик. Дані кошика зберігаються у `CartModel` за
допомогою `ChangeNotifier`, а доступ до стану надано через `Provider`.

Після цього створено форму оформлення замовлення. У ній потрібно заповнити
ім’я, телефон і адресу доставки. Перевіряється, чи всі поля заповнені, чи
телефон має правильний формат і чи адреса містить не менше 10 символів.
Кнопка підтвердження стає активною тільки після правильного заповнення
форми. Після підтвердження відкривається екран успішного замовлення.

Для перевірки інтерфейсу написано 19 Widget-тестів. Вони охоплюють показ
знижки та рейтингу, роботу кнопок, обмеження кількості товару, підрахунок
суми кошика й перевірку форми. Додатково написано 3 unit-тести для
`CartModel`. Окремо підготовлено Integration-тест, який відтворює весь
сценарій: від відкриття магазину до підтвердження замовлення.

## Команди для перевірки

```bash
flutter pub get
flutter test
flutter devices
flutter test integration_test/app_test.dart -d emulator-5554
```

Для Integration-тесту потрібно підставити реальний ID Android-пристрою.
У середовищі підготовки проєкту Flutter SDK не був доступний, тому результати
запуску тестів необхідно перевірити на комп’ютері з установленим Flutter.

## Висновок

Під час лабораторної роботи розроблено інтерфейс онлайн-магазину та
підготовлено тести для перевірки його основних функцій. На цьому прикладі
можна побачити різницю між Widget-тестами, які перевіряють окремі частини
програми, та Integration-тестом, що перевіряє роботу застосунку від початку
до завершення покупки.
